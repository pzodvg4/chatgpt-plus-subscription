## 订阅成功后的管理：取消、退款和扣费故障

取消订阅：点头像进 Settings → Account，找到订阅管理操作取消。取消后当前周期会用到结束，不会立刻失效。

**付款成功但账号还显示 Free**，是最高频的故障，按这个顺序排查：

1. 确认登录的是付款的那个账号。在 Settings → Account 里查看当前账号邮箱——收据邮箱和 ChatGPT 账号邮箱有可能是两个不同的邮箱。
2. 用 Apple 登录且开启了“隐藏邮箱”的，账号地址可能是 @privaterelay.appleid.com 结尾，要用 Continue with Apple 加同一个 Apple 账号才能登回去。
3. 手机端打开 Settings → Restore purchases，同步一次订阅状态。
4. 以上都不行就退出登录，重新登录付款账号；仍未解决就联系客服，附上收据或被扣款卡号的后四位，方便对方定位订单。

退款：如果认为被错误扣费，可以在帮助中心提交退款申请，批准后一般 5–10 个工作日退回。发票和账单同样在 Settings → Account 里查看、下载。
